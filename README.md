# First Web Page HTML CSS JavaScript

This example demonstrates the fundamental building blocks of a web page: HTML for structure, CSS for styling, and JavaScript for interactivity. It creates a simple 'Hello World' style page with a button that changes text, illustrating the core concepts for beginners. This single file showcases how these three technologies work together to form a basic web experience.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
3. Click the 'Mesajı Değiştir' button to see JavaScript in action.
